# Captures (archive)

Ces captures datent de la phase 4 : interface d'avant les lots 1 à 6, avec des photos de marques réelles. Elles ne montrent plus l'app actuelle.

Les captures à jour sont produites par les vérificateurs de chaque lot (`docs/lots/lot-*/`) et restent hors dépôt. Pour voir l'app, suivez [`DEMO.md`](../../DEMO.md) ou le [guide d'essai](../GUIDE_ESSAI.md).
